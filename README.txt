BCA111P - Lab Sheet 07
String Handling using Built-in Functions in C++

This ZIP contains 20 separate C++ source files in serial order (01 to 20),
matching the question list in the supplied lab sheet.

How to use:
1. Open a .cpp file in Code::Blocks, Dev-C++, Visual Studio, or another C++ IDE.
2. Compile and run each program separately.
3. Enter the requested input when prompted.

Important notes:
- Programs use char arrays and <cstring> functions to match the lab sheet.
- strrev() is not part of standard C++; Program 10 uses a portable loop to reverse.
- Program 11 similarly builds a reversed string and compares it for palindrome.
- Program 4 copies the first string with strcpy() and compares the copy using strcmp(),
  since strcpy() itself does not compare strings.
- Anagram checking ignores spaces and letter case.
